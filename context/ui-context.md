### ⚠ The revamp: lead status/stage taxonomy unification

This is the primary, concrete difference between the Figma export and the live app, and the thing this automation task should be built around:

- **Figma's Dashboard Conversion Funnel** used its own distinct 8-stage vocabulary: `Enquiry → Contacted → Interested → Qualified → In discussion → Proposal → Negotiation → Converted`.
- **The live Dashboard's Conversion Funnel now uses the same unified 10-status taxonomy** as the Analytics/Agents/Reports pages already did: `Prospect → Contacted → Market Qualified → Parked → Sales Qualified → Interested → In Discussion → Onboarded → Won → Lost`.
- **The Leads list table's Status column** also now shows values from this same unified taxonomy (e.g. "Prospect") rather than the Figma's ad-hoc labels ("Not started", "Closed Won", "Approved").
- Net effect: every lead-status concept across the whole LMS module (Dashboard, Leads list, Analytics, Agents distribution, Reports filter) now shares one consistent 10-value enum, where the Dashboard previously had its own separate one.
