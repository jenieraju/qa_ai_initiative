- **Row 10's and row 25's "no results" copy is partially unconfirmed** — row 25's is Figma-documented (`"No data to show!"`); row 10's leads-list equivalent is inferred by analogy, not directly confirmed in `LMS.pdf` (no empty-state variant was shown for the List tab itself, only for Analytics/Dashboard/Agents/Sources).
