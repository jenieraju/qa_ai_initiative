## Overview

Revamp of the Lead Management module in CoFee. This epic covers five pages:

- **Lead Dashboard** — already exists, being completely revamped; data inside built from scratch.
- **Leads List** — already exists; only minor updates (Days Stuck column + List/Analytics toggle).
- **Leads Analytics** — new Analytics view on the Leads page; carries the metrics/graphs previously shown on the old Dashboard, plus a new Conversion/Distribution view on two graphs.
- **Agents** — new tab, built from scratch.
- **Sources** — new tab, built from scratch (includes an Ad sources drill-down sub-page).

## Stories

- Revamped Lead Dashboard
- Leads List updates (Days Stuck column & List/Analytics toggle)
- Leads Analytics view
- Agents page
- Sources page (incl. Ad sources)
